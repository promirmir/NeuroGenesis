# Foundation Brain — isolated checkpoint inference laboratory

**Public credit: Miron przy pomocy AI.** Research feature, not a conversational AI release.

## What is actually implemented

`neurogenesis/foundation_infer.py` loads an **explicitly trusted, existing local numerical checkpoint** with the project's `FoundationBrain.load_checkpoint(..., weights_only=True)` path. It checks `training_steps >= 1`, keeps the trained multiscale GRU in `eval()` + `torch.inference_mode()`, and repeatedly calculates the next-byte logits from a bounded rolling UTF-8 byte context. At each step it greedily selects the highest-logit byte.

This is **actual trained-weight inference**, not retrieval, fabricated output or manually programmed sentences. It may output random or invalid UTF-8. The result includes raw hexadecimal bytes, a replacement-decoded display, whether UTF-8 was valid, the mean log-probability of selected bytes and measured output bytes/second. Those are **not** calibrated answer confidence, quality, intelligence or factual accuracy.

Inference never reads websites, contacts external models, writes to the operator's SQLite memory, promotes weights into chat or claims citations. Default Tk EXE is unchanged. A new isolated experiment panel in the optional Qt Command Center displays its ungrounded output **separately from the sourced conversation**.

## Running a local pilot

Install optional PyTorch in the same Python environment used for local training; provide a checkpoint produced by `knowledge_train` or `foundation_train` (never an untrusted download).

```powershell
py -3.12 -m pip install -e ".[foundation]"
py -3.12 -m neurogenesis.foundation_infer --checkpoint "C:\\private\\foundation-candidate.pt" --prompt "Neurony i synapsy" --bytes 16 --device cpu --confirm-local-checkpoint
```

Qt: open **Trening**, select the local `.pt` file, enter a prefix, choose 1–64 output bytes and CPU/CUDA, check that the file is trusted, and click **Wykonaj predykcję z wag**. No automatic model loading occurs on launch. Inference executes in a daemon worker thread and returns through an event queue; Stop cancels further decoding. Raw model output is NOT inserted into the normal conversation.

## Safety and reliability gates

- Requires explicit trusted-checkpoint acknowledgment for every command/session. A locally sourced file is still unsafe if its provenance is unknown; `weights_only=True` reduces pickle risk but is not a complete security sandbox. Never load externally supplied model files without independent verification.
- Paths must point to a regular, non-symlink `.pt` or `.pth` file, and the checkpoint must have valid numerical parameters and at least one recorded training step. No implicit model downloads.
- Prefix max 512 Unicode characters; at least two encoded bytes; uses at most the checkpoint's configured sequence length and up to **64 generated bytes**. Generates with a sliding local context, not a persistent recurrent state across entire conversation; no long-memory or reasoning claim.
- Explicit CPU/CUDA option, no GPU claims until physical hardware measurements. May be slow for long prompts; Qt keeps the main loop responsive and supports cancellation between decode steps.
- Outputs can be malformed UTF-8. Hexadecimal bytes preserve the actual sampled prediction rather than silently pretending to have generated coherent language.
- No training writes, no mutation of private SQLite, no autonomous network or new OS permissions. The existing sourced chat path remains authoritative.

## Required tests

`tests/test_foundation_infer.py` verifies actual CPU logits against the first generated byte, stable reload/greedy outputs, trained-vs-untrained checks, trust and resource validation, cancellation, a genuinely asynchronous service worker and no change to the existing SQLite brain/teachings.

Dedicated GitHub `foundation-cpu.yml` installs real PyTorch CPU, runs this suite and existing foundation/rights/retention regressions. Qt Windows/Ubuntu offscreen and Windows Tk + experimental frozen Qt EXE remain separate gates.

## Remaining blocker before model-based chat

A byte-level GRU trained on a few local documents is **not yet a competent language model**. Before its output can become a conversational answer, establish an independent licensed natural-language/QA corpus, prospective document-disjoint evaluation, comparisons against Markov and matched baselines, grounded source attribution, calibrated abstention, old-skill retention and safe candidate promotion/rollback. Neural output must never inherit a URL merely because a separate retrieval component found it; claims must be traceable to source evidence independently.

No v1, AGI, consciousness, or claimed human-brain equivalence follows from this step.
